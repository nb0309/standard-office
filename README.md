# SmartOffice Analytics

This repository hosts **installer releases only**. There is no application source here.

Download `SetupSmartOfficeAnalytics.exe` from the
[latest release](https://github.com/nb0309/standard-office/releases/latest).

Installed copies of the app check this repository for updates (`latest.json` plus
the setup file). You can also run a new setup file by hand; it replaces the
program and does not touch data in `%AppData%\Roaming\SmartOfficeAnalytics`.
